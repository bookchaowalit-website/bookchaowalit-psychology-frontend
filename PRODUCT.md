# Psychology Explorer

## Product truth

Psychology Explorer is a calm educational index of psychology concepts,
questions, and everyday examples. It is for learning and reflection, not
diagnosis, treatment, or crisis support.

## First release

- Browse concepts by theme.
- Read a concise explanation and a grounded everyday example.
- Save a reflection prompt locally in the browser.
- Make the boundary between education and clinical advice explicit.

## Evidence boundary

The first release contains short, self-authored learning notes. It is not a
clinical reference and should not replace a qualified professional.
